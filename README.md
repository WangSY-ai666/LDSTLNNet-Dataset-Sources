# LDSTLNNet Dataset Sources

Official source links for the public industrial surface defect datasets used in this study.

## 1. KSDD2

**Kolektor Surface-Defect Dataset 2 (KSDD2)**

Official source:  
https://www.vicos.si/resources/kolektorsdd2/

## 2. STEEL

**Severstal: Steel Defect Detection**

Official source:  
https://www.kaggle.com/competitions/severstal-steel-defect-detection

## 3. DAGM 2007

**DAGM 2007 Dataset**

Official source:  
https://zenodo.org/records/12750201

## 4. NEU-DET

**NEU Surface Defect Database (NEU-DET)**

Official source:  
https://faculty.neu.edu.cn/songkc/en/zdylm/263265
